## What would flip a no

- If it caught a deadline my WhatsApp groups missed, like a submission date a professor only posted on the portal. I did miss one last semester, so that would make me keep it.
- If it actually had my marks and timetable changes before the WhatsApp group did, so it was the fastest place to find out, I'd keep it.
- If it synced deadlines and exam notices straight into my Google Calendar automatically, so I could stop copying them over by hand.
- If it pushed the notices straight into WhatsApp, or if professors stopped posting in the groups and only used this app, so I had no choice.
- If my whole class group, including the CR, started using it and stuff showed up there first and more accurately than on WhatsApp.
- If it pushed deadlines and exam notices straight into my Google Calendar or Notion automatically, so I never had to open the app at all.
- If my whole friend group started using it and the alerts actually saved me from missing a submission at least once, so it beats hearing it from friends.
- If the university made it the official place where deadlines and exam notices go first, and showed clearly that it only reads announcements and nothing from my email or marks.
- If it had all the club and fest stuff from day one, like event registrations, practice schedules and fest updates, so my whole extracurricular life was in it and not just exam notices.
- If it pinged me about a deadline the group chat missed, or my whole friend group started using it instead of WhatsApp.
- If the college stopped posting notices in WhatsApp groups and UniDash became the only place to get exam dates and deadlines first.
- If it only alerted me for things that actually affect me, like my own exam dates and assignment deadlines, and my friends were all using it, so missing it meant missing stuff.

Buyers say they would buy **3.0 times** in the first month on average.
